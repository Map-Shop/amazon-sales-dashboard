Note: Amazon's order reports typically only go back ~2 years. Very old months may fail — check the status panel for any errors.

Bulk Upload Changes

CSV Format Required
Columns must be:
Date | ASIN | Changes | Notes

• Date: any common format — auto-converted to YYYY-MM-DD (e.g. 4/30/26, Apr 30 2026, 2026-04-30)
• ASIN: Must match a product in the Upstash catalog
• Changes: Comma-separated if multiple (e.g., "Title, Bullet Points")
• Notes: Optional text
